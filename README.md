# 📱 Mobile Sales Dashboard | Power BI

An interactive Power BI dashboard built to analyze mobile phone sales performance across brands, models, cities, and payment methods — helping surface trends in revenue, volume, and customer satisfaction at a glance.

## 🔍 Overview

This dashboard turns raw mobile sales transaction data into a single-page, decision-ready view. It's designed for quick scanning: high-level KPIs up top, then drill-down visuals for geography, trends, product mix, and customer feedback.

## 📊 Key Features

- **KPI Cards** – Total Sales, Total Quantity, Transactions, and Average Sale Value at a glance
- **Geo Map** – Total Sales by City to spot regional performance
- **Trend Line Chart** – Total Quantity sold over time to track demand patterns
- **Bar Chart** – Total Sales by Mobile Model, ranking top and bottom performers
- **Pie Chart** – Transactions split by Payment Method
- **Funnel Chart** – Customer Ratings distribution
- **Area Chart** – Total Sales by Day of Week
- **Detail Table** – Brand-level breakdown of Sales, Quantity, and Transactions
- **Interactive Slicers** – Filter the entire report by Mobile Model, Payment Method, Brand, and Day Name

## 🛠️ Tools & Skills Used

- **Power BI Desktop** – data modeling, DAX measures, report design
- **DAX** – calculated measures (Total Sales, Total Quantity, Transactions, Average)
- **Data Visualization** – KPI cards, geo mapping, trend analysis, funnel/pie charts
- **Interactive Filtering** – slicers for dynamic, self-service exploration

## 🚀 How to View

1. Download `Mobile_Sales_Dashboard.pbix`
2. Open it in [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop) (free)
3. Explore the report — use the slicers to filter by brand, model, payment method, or day

Built as a hands-on project to practice end-to-end BI workflow: data modeling → DAX measures → visual storytelling → interactive dashboard design.
